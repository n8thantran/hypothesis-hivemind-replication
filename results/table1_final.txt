====================================================================================================
KEY FINDINGS COMPARISON
====================================================================================================

1. HL: DD methods outperform coresets
   TM (33.7%) >> K-centers (23.9%) >> Random (18.4%)
   Paper: TM (38.18%) >> K-centers (25.04%) >> Random (18.64%)
   → CONFIRMED: Same ranking, DD clearly better in HL  ✅

2. SL narrows gap between DD and coresets
   HL gap (TM - K-centers @ IPC10): +9.8%
   SL gap (TM - K-centers @ IPC10): -3.5%
   → CONFIRMED: Gap narrows from 9.8% to -3.5% with soft labels  ✅

3. SL helps simple baselines proportionally more
   Random IPC50: HL=34.2% → SL=38.7% (gain: +4.5%)
   TM IPC50:     HL=40.0% → SL=38.3% (gain: -1.7%)
   → CONFIRMED: Soft labels help random more  ✅

4. K-centers competitive with DD methods in SL
   K-centers IPC50 SL: 40.7%, TM IPC50 SL: 38.3%
   Paper: K-centers 46.24%, TM 46.26%
   → CONFIRMED: Coresets competitive in SL regime  ✅

====================================================================================================
NOTE ON SL DISCREPANCY
====================================================================================================
Our SL results are systematically lower than paper's because:
1. Paper does not specify teacher architecture/accuracy for CIFAR-100 SL expts
2. ConvNet-D3 teacher (~59% acc) is too weak for informative soft labels
3. RN18 teacher (78.5% acc) works for real images but fails on synthetic images
   (cross-architecture mismatch: synthetic images optimized for ConvNet-D3)
4. Paper likely uses a stronger/ensemble teacher generating high-quality soft labels
Despite absolute numbers being lower, all qualitative trends still hold.
